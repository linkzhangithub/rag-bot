## 3. 核心项目详解

### 项目一：AI 对话助手（线上：ai.link2ai.online）

#### 项目背景

个人作品集项目，旨在展示全栈 + AIGC 应用开发能力，实现一个支持多模态输入的智能对话系统。

#### 技术架构

- **前端**：Vue 3 + Pinia + Vite + Markdown-it + Highlight.js
- **后端**：Node.js + Express + 智谱 AI SDK + 讯飞 WebSocket
- **部署**：EdgeOne Pages（全球可用区，免备案）

#### 核心功能与实现细节

**1. 流式对话**

- 使用智谱 `glm-4-flash` 模型的 `stream: true` 参数，后端通过 SSE（Server-Sent Events）向前端逐字推送。
- 前端逐字追加到消息框，提升响应速度与用户体验。
- 实现了中断请求、错误重试机制。

**2. 图片理解**

- 前端压缩用户上传图片（Canvas 压缩至 1MB 内），转为 base64 发送。
- 后端调用智谱 `glm-4v-flash` 多模态模型，返回图片描述。
- 支持拖拽上传、粘贴上传。

**3. 语音输入**

- 集成讯飞实时语音听写 WebSocket API。
- 前端录制 PCM 音频流，实时发送至讯飞服务，返回识别文字并填入输入框。
- 处理了音频权限、网络断线重连、识别结果校正。

**4. 多角色切换**

- 内置四种角色：智能助手、前端面试官、心理导师、贴吧老哥。
- 每个角色对应不同的 system prompt，切换时更新对话上下文。
- 角色配置存储在 Pinia 中，支持本地持久化。

**5. 对话历史管理**

- 自动保存对话至 localStorage，按时间分组（今天/昨天/7天内等）。
- 支持新建对话、删除对话、切换对话，数据不丢失。
- 使用 AI 智能生成对话标题（先截取后调用智谱 API 优化）。

**6. 响应式与性能优化**

- 移动端适配（媒体查询、flex 布局）。

#### 技术难点与解决方案

| 难点              | 解决方案                                            |
| :-------------- | :---------------------------------------------- |
| 流式输出时 UI 卡顿     | 使用 `requestAnimationFrame` 批量更新 DOM，减少重绘次数      |
| 讯飞 WebSocket 断连 | 实现心跳检测（每 30 秒发送 ping），自动重连并恢复识别                 |
| 多角色切换后上下文丢失     | 设计 `conversations` 数据结构，每个对话独立存储角色 ID 和消息       |
| 云函数标题生成 405 错误  | 修正 EdgeOne 云函数导出格式为 `onRequest(context)`，解决路由匹配 |

#### 项目成果

- 支持 Chrome、Edge、Safari 主流浏览器。
